# Weather App

Kotlin Android app for looking up weather by city name. Search shows current conditions, a zoomed view focuses on °C, and a health screen lists tips when the weather data suggests warnings.

Uses the [OpenWeather](https://openweathermap.org/) API.

## Features

- Weather search results
- Zoomed temperature view
- Health report based on weather conditions

## Run

1. Clone the repo:

   ```bash
   git clone https://github.com/Richard19Perez77/WeatherApp.git
   ```

2. Add an OpenWeather API key where the app reads it.
3. Open the project in Android Studio and run the `app` configuration.
